AXI_TOP 模块设计报告

TPU_TOP 数据搬运子系统 · 独立 M/RX 与 S/TX 通路 · AXI4-Stream 桥接及两份 FIFO

数据宽度512-bit TDATA
64-bit TKEEP/TSTRB
独立通路M：AXI → FIFO_IN
S：FIFO_OUT → AXI
握手机制TVALID/TREADY
仅在双方为高时传输
边界标识TLAST 与 DATA 同项存储
保持至成功消费
当前设计范围：包含 axi2fifo、fifo_in、fifo_out 和 fifo2axi 四个核心模块，并由 AXI_M_TOP、AXI_S_TOP 分别集成。两条通路互相解耦，不共享事务状态。

1. 模块定位与拓扑

AXI_TOP 由输入搬运和结果发送两条独立链路组成。M/RX 通路接收外部 AXI4-Stream 数据并缓存给 CTRL；S/TX 通路缓存 SA_TOP 结果并发送到外部 AXI4-Stream。两侧可在各自条件满足时独立工作。

2. 核心行为

axi2fifo · 输入桥接

EN 与 START 启动接收。rd_tvalid && rd_tready 时写 FIFO；PRE_FULL 拉高即撤销 READY，TLAST 成功握手后结束本次输入事务。

fifo_in · 输入缓存

默认深度 8，预满阈值 7。DATA 和 LAST 组成同一存储项，CTRL 通过 FWFT 队首接口读取。

fifo_out · 结果缓存

将 data_out[15:0][31:0] 打包成一拍 512-bit 数据。当前接口不导出 FULL，系统调度必须保证未消费结果不超过 8 拍。

fifo2axi · 输出桥接

FIFO 非空且使能有效时开始输出，不等待 START。反压时保持 VALID、DATA、LAST 和 USER，只有成功握手才读取 FIFO。

cpu_cpt_mode 是任务期间稳定的静态配置，高位决定 wr_tuser。rpt_cpt_cyc 在复位或 START 时清零，每次成功输出一个 512-bit 数据拍加 1；它不是 M 侧输入计数，也不受 FIFO 深度限制。

4. 两份独立 FIFO

两份 FIFO 都是单时钟、低有效异步复位的 FWFT 同步 FIFO。每个条目保存 512-bit DATA 和 1-bit LAST。复位后 EMPTY=1，空队列的数据和 LAST 输出为 0。

材料与笔记

        

          

            
AXI_TOP 模块设计方案

            
根据原始 4.7 节设计截图整理，并按当前 RTL 接口修订。

            
4.7.1 概述

            
AXI_TOP 是 TPU_TOP 内部的数据搬运单元，负责在系统控制逻辑调度下，实现片外 AXI4-Stream 接口与片内 FIFO 缓冲之间的数据交换。

            
输入侧从外部总线接收待计算数据并写入 FIFO_IN，供 CTRL 使用；输出侧从 FIFO_OUT 读取 SA_TOP 的计算结果，并通过 AXI4-Stream 将结果发送回外部接收端。当前实现将两侧拆分为独立的 AXI_M_TOP 与 AXI_S_TOP。

            
4.7.2 主要特性

            

              
双向搬运
支持 AXI4-Stream TVALID/TREADY 握手，完成输入接收与结果发送。

              
读写分离
接收与发送通路相互独立，通过 FIFO 解耦数据生产和消费速率。

              
受控启动
START 启动 M 侧输入事务；S 侧根据使能和 FIFO 非空状态独立发送。

              
流量控制
FIFO_IN 使用 PRE_FULL 提前施加输入背压；FIFO_OUT 使用 EMPTY 防止无效读取。

            

            
4.7.3 当前接口口径

            
总线数据宽度为 512 bit。FIFO_IN、FIFO_OUT 默认深度均为 8；FIFO_IN 默认预满阈值为 7。FIFO_OUT 接收 16 路 32-bit 结果，不再导出 FULL 端口，容量安全由系统调度保证。

          

          

            
AXI_TOP 基础测试方案

            
设计阶段仅使用基础 SystemVerilog testbench，不引入 UVM、断言计划或覆盖率计划。

            
1. M/RX 输入通路

            
发送带 TLAST 的多拍 AXI 输入数据，先保持 FIFO 读端暂停，使 PRE_FULL 自然拉高并形成背压；随后恢复 CTRL 读取，检查数据顺序、内容及 LAST 对齐。

            
2. S/TX 输出通路

            
向 FIFO_OUT 写入 16×32-bit 结果，检查打包后的 512-bit 数据、TKEEP/TSTRB、USER、TLAST 和 rpt_cpt_cyc。接收端暂停时，输出负载必须保持不变。

            
3. 通过条件

            
两条通路均完成；数据数量、内容、顺序和 TLAST 全部一致；背压期间没有丢拍、重复拍、非法写入或提前读取。TB 输出明确的 PASS/FAIL。
